# Конвертер книг в аудиокниги (локальный)

Превращает EPUB/FB2/TXT в аудиокнигу. Полностью локально: синтез речи —
[Silero TTS](https://github.com/snakers4/silero-models) на CPU, без облачных API
и без ключей.

## Требования

- Python **3.9+** (проверено на 3.14)
- **ffmpeg** в `PATH` — нужен для кодирования итогового файла

## Установка

```bash
git clone <repo>
cd txt2a
pip install -r requirements.txt
```

Рекомендуется виртуальное окружение:

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # Linux / macOS
pip install -r requirements.txt
```

### ffmpeg

```bash
winget install Gyan.FFmpeg    # Windows
brew install ffmpeg           # macOS
sudo apt install ffmpeg       # Debian / Ubuntu
```

На Windows после установки **перезапусти терминал**: winget добавляет ffmpeg в PATH
только для новых процессов. Проверить — `ffmpeg -version`.

Без ffmpeg можно обойтись, поставив `output.format: wav` в `config.yaml`, но файл
получится примерно в десять раз больше, а `speed` применяться не будет.

## Использование

1. Положи книги в папку `books/`
2. Запусти:
   ```bash
   python src/main.py
   ```
3. Готовые аудиокниги появятся в `output/`

При первом запуске скачивается модель Silero (~145 МБ) в `models/`.

Прерванный запуск продолжается с места остановки: уже синтезированные фрагменты
лежат в `temp/<имя книги>/` и повторно не считаются. Если поменял параметры
разбиения текста (`chunk_size`, `max_sentence_length`) — удали `temp/<имя книги>/`,
иначе подхватятся фрагменты от прежнего разбиения.

## Настройка

Редактируй `config.yaml`:

| Параметр | Описание |
|---|---|
| `tts.voice` | голос: `aidar`, `baya`, `kseniya`, `xenia`, `eugene` |
| `tts.sample_rate` | только `8000`, `24000` или `48000` |
| `tts.speed` | `0.8`–`1.3`; меняет темп, не задирая высоту голоса |
| `processing.chunk_size` | символов на фрагмент синтеза (300–400) |
| `output.format` | `m4b`, `mp3` или `wav` |
| `output.bitrate` | например `96k` |
| `output.normalize` | выравнивание громкости по EBU R128 на −18 LUFS |
| `output.remove_silence` | схлопывает паузы длиннее 0.7 с |

## Производительность

На Intel i9 (без GPU), измерено на главе в ~14 тыс. символов:

- 15 минут звука синтезируются за ~40 секунд, то есть **≈23× реального времени**
- книга на 10 часов — ориентировочно 25–40 минут

## Форматы

- **EPUB** — главы читаются в порядке spine (порядок чтения), а не в порядке файлов
- **FB2** — главами считаются секции верхнего уровня; кодировка берётся из XML-пролога
- **TXT** — одна глава; кодировка определяется автоматически (UTF-8, cp1251, koi8-r)
