# Конвертер книг в аудиокниги (локальный)

## Установка

```bash
git clone <repo>
cd audiobook_converter
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Использование

1. Положи книги в папку `books/`
2. Запусти:
   ```bash
   python src/main.py
   ```
3. Готовые аудиокниги появятся в `output/`

## Настройка

Редактируй `config.yaml`:
- `voice` — выбери голос (`baya`, `kseniya`, `aidar` и др.)
- `chunk_size` — размер текстового блока (рекомендуется 300–400)
- `format` — `m4b` или `mp3`

## Производительность

На Intel i9 (без GPU):
- Скорость синтеза ≈ 20–25× реального времени
- Книга на 10 часов ≈ 25–40 минут синтеза

## Рекомендации

- Используй Silero для лучшего качества русского языка
- Для максимальной скорости можно добавить multiprocessing
- Храни модель в папке `models/` (скачивается автоматически)
