# CLAUDE.md

Этот файл — инструкции для Claude Code при работе с этим репозиторием.

## Что это за проект

`txt2a` — локальный (без облачных API) конвертер книг в аудиокниги. На вход — EPUB/FB2/TXT
из `books/`, на выход — аудиофайл в `output/`. Синтез речи — Silero TTS на CPU, русский язык.

## Команды

```bash
# установка зависимостей
pip install -r requirements.txt

# запуск конвертации всех книг из books/
python src/main.py
```

**Важно:** запускать только из корня проекта. `main.py` использует плоские импорты
(`from text_extractor import ...`), а `config.yaml` и все пути из секции `paths`
открываются относительно текущей рабочей директории.

Внешние зависимости вне pip: **ffmpeg** должен быть в `PATH` — `pydub` вызывает его
для экспорта MP3.

## Архитектура

Пайплайн линейный, собирается в `src/main.py:process_book()`:

1. **`text_extractor.py`** — `extract_text()` диспетчеризует по расширению:
   EPUB через `ebooklib` + BeautifulSoup (`html.parser`), FB2 через BeautifulSoup
   (`xml`), TXT — прямое чтение UTF-8. Далее `clean_text()` сжимает кратные
   пробелы и переносы строк.
2. **`text_processor.py`** — `split_into_chunks()` режет текст по границам предложений
   (regex по `.!?`) в блоки не длиннее `processing.chunk_size` символов.
3. **`silero_tts.py`** — класс `SileroTTS`: при создании скачивает модель в
   `models/`, грузит её через `torch.package.PackageImporter` и синтезирует
   чанк за чанком в WAV (`torchaudio.save`). Один чанк = один файл
   `temp/<имя книги>/chunk_NNNN.wav`.
4. **`audio_postprocess.py`** — `concatenate_chapters()` склеивает WAV-ы через
   `pydub` и экспортирует итоговый файл.

## Конфигурация

Все настройки — в `config.yaml` (голос, скорость, размер чанка, формат, пути).

Учти расхождение между конфигом и кодом — часть параметров объявлена, но ещё не
подключена:

- `output.format: m4b` игнорируется — `main.py` всегда пишет `.mp3`, а
  `concatenate_chapters()` хардкодит `format="mp3"` и `bitrate="96k"`.
- `output.normalize` / `output.remove_silence` не читаются; `normalize_audio()`
  существует, но нигде не вызывается.
- `processing.pause_between_paragraphs` / `pause_between_chapters` не применяются;
  `add_ssml_pauses()` в `text_processor.py` написана, но не подключена к пайплайну.
- `tts.speed` читается в `SileroTTS.__init__`, но не передаётся в `apply_tts()`.

Если правишь что-то из этого списка — подключай параметр к коду, а не дублируй
значение константой.

`SileroTTS` читает `config.yaml` самостоятельно, хотя `main.py` уже загрузил его и
передаёт `config` в остальные шаги. При рефакторинге лучше передавать конфиг
в конструктор, а не читать файл второй раз.

## Соглашения

- Код и комментарии — на русском, docstring-ом в одну строку у каждой функции.
- Пути — только `pathlib.Path`, не строки (в сторонние API отдаются через `str()`).
- Ошибки синтеза не прерывают обработку книги: `SileroTTS.synthesize()` печатает
  ошибку и возвращает `False`, чанк просто пропускается. Сохраняй это поведение —
  книга на тысячи чанков не должна падать целиком из-за одного.

## Что не коммитим

`books/`, `output/`, `temp/`, `models/` — пользовательский контент, промежуточные
файлы и скачанная модель (~60–100 МБ). См. `.gitignore`.
