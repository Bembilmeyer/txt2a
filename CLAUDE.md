# CLAUDE.md

Этот файл — инструкции для Claude Code при работе с этим репозиторием.

## Что это за проект

`txt2a` — локальный (без облачных API) конвертер книг в аудиокниги. На вход — EPUB/FB2/TXT
из `books/`, на выход — аудиокнига в `output/`. Синтез речи — Silero TTS на CPU, русский язык.

## Команды

```bash
pip install -r requirements.txt
python src/main.py          # конвертирует все книги из books/
```

Запускать можно из любой директории: `main.py` вычисляет `PROJECT_ROOT` как родителя
`src/`, и все пути из секции `paths` разрешаются относительно него (`resolve_path()`).

Внешние зависимости вне pip: **ffmpeg** в `PATH` — им кодируется итоговый файл.
Без ffmpeg работает только `output.format: wav`. На Windows ставится через
`winget install Gyan.FFmpeg`, после чего **нужен перезапуск терминала** —
winget правит PATH только для новых процессов.

## Архитектура

Пайплайн линейный, собирается в `src/main.py:process_book()`:

1. **`text_extractor.py`** — `extract_chapters()` возвращает **список глав**, а не одну
   строку: без границ глав некуда применять `pause_between_chapters`. EPUB обходится
   **в порядке spine**, а не в порядке `get_items()` — иначе главы идут вперемешку.
   FB2 читается байтами (кодировка объявлена в XML-прологе и часто это cp1251),
   главы — секции верхнего уровня `<body>`. TXT считается одной главой, кодировка
   подбирается перебором (`_ENCODINGS`).
2. **`text_processor.py`** — `split_into_chunks()` возвращает список `Chunk(text,
   pause_after_ms)`. Абзацы обрабатываются по отдельности, поэтому чанк никогда не
   склеивает конец одного абзаца с началом другого; на этом стыке ставится пауза.
   Предложения длиннее лимита дорезаются по запятым, затем по словам (`_hard_split`).
3. **`silero_tts.py`** — класс `SileroTTS` получает **готовый `config` в конструктор**
   (файл сам не читает). Пишет моно-WAV 16 бит через stdlib `wave`.
4. **`audio_postprocess.py`** — `concatenate_wavs()` склеивает WAV потоково (книга на
   10 часов — это ~3.4 ГБ PCM, в память такое грузить нельзя), вставляя паузы.
   Затем `encode_audiobook()` одним вызовом ffmpeg делает фильтрацию и кодирование.

## Важные подводные камни

Это места, где уже были ошибки — не ломай их обратно:

- **`model.to(device)` у Silero не возвращает `self`.** Это не `nn.Module`, а объект из
  `torch.package`. Писать `self.model = importer.load_pickle(...).to(device)` нельзя —
  получится `None`, и синтез упадёт на каждом чанке с `'NoneType' object has no
  attribute 'apply_tts'`.
- **`pydub` несовместим с Python 3.13+** и из проекта удалён. Он импортирует `audioop`,
  удалённый из stdlib по PEP 594. Не возвращай его и не добавляй шим `audioop-lts` —
  вся работа с WAV делается модулем `wave`, а всё остальное отдано ffmpeg.
- **`torchaudio` тоже удалён** из зависимостей: `torchaudio.save()` объявлен устаревшим
  в пользу `save_with_torchcodec` и тянет ffmpeg-библиотеки. Модель Silero его не
  импортирует — проверено.
- **После `loudnorm` обязателен `aresample`.** Фильтр внутри работает на 192 кГц и
  отдаёт поток с этой частотой; кодер округлит её до ближайшей поддерживаемой
  (для AAC — 96 кГц) и зря закодирует апсемплированный звук. См. `_restore_sample_rate()`.
- **`tts.speed` реализован через ffmpeg `atempo`**, а не средствами Silero (SSML
  `prosody rate` требовал бы XML-экранирования произвольного текста книги). `atempo`
  работает только в диапазоне 0.5–2.0, поэтому раскладывается в цепочку.
  Следствие: при `format: wav` скорость не применяется.

## Конфигурация

Все настройки — в `config.yaml`. Все параметры подключены к коду; если добавляешь
новый — подключай его, а не дублируй константой в коде.

- `tts.sample_rate` — только 8000/24000/48000, иначе Silero падает (проверяется заранее).
- `output.format` — `mp3`, `m4b`/`m4a` или `wav`. Расширение итогового файла задаётся
  этим параметром, а не хардкодом.
- `output.normalize` — `loudnorm` на −18 LUFS (ориентир для аудиокниг), не пиковая
  нормализация: у синтеза плавает громкость между чанками.
- `output.remove_silence` — схлопывает паузы **длиннее 0.7 с**; более короткие
  (в том числе наши межабзацные) сохраняются намеренно.

## Поведение при ошибках

Книга на тысячи чанков не должна падать целиком из-за одного:

- `SileroTTS.synthesize()` печатает ошибку и возвращает `False` — чанк пропускается.
- Готовые WAV не синтезируются заново, так что прерванный запуск продолжается
  с места остановки. Поэтому при изменении логики разбиения текста
  **нужно чистить `temp/<книга>/`** — иначе подхватятся чанки от старого разбиения.
- Наличие ffmpeg проверяется в `main()` **до** синтеза, а не на этапе кодирования.

## Соглашения

- Код и комментарии — на русском, docstring в одну строку у каждой функции.
- Комментарии объясняют **почему**, а не что: в коде много неочевидных обходов
  чужих багов, и именно они должны быть объяснены.
- Пути — только `pathlib.Path` (в сторонние API отдаются через `str()`).
